# Azarya.dev — Final Portfolio

## Cara menjalankan
1. Extract folder `Azarya_Portfolio_Final`.
2. Buka folder ini di VS Code.
3. Pastikan file `images/FOTO1.jpeg` ada.
4. Install extension **Live Server** (Ritwick Dey) jika belum.
5. Klik kanan `index.html` → **Open with Live Server**.

## Dibuka dari HP
- Laptop dan HP harus tersambung ke Wi-Fi yang sama.
- Di VS Code Settings, cari `Live Server: Host` lalu set `0.0.0.0` (atau tambahkan ke settings.json: `"liveServer.settings.host": "0.0.0.0"`).
- Buka alamat IPv4 laptop, misalnya `http://192.168.x.x:5500`, dari browser HP.
- Jika tidak terbuka, izinkan VS Code/Code pada Windows Firewall untuk jaringan Private.
